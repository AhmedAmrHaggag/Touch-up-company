3AG BILINGUAL WEBSITE
=====================

Included:
- index.html                 Home page
- service-details.html       Service detail page
- style.css                  Shared styling and RTL layout
- script.js                  Home page interactions
- service-details.js         Dynamic service content
- language.js                English/Arabic switching and back-to-top button

To try it:
1. Keep the files and folders together.
2. Open index.html in a browser. An internet connection is needed for Tailwind CDN,
   Google Fonts, and the remote Unsplash images.
3. Use the العربية / English button in the top navigation. The selected language
   is saved in this browser and is shared by both pages.
4. Scroll down to reveal the round back-to-top button at the lower-right corner.

MEDIA NOTE:
The uploaded files refer to local images, videos, and GIFs under images/, videos/,
and gif/. Those media files were not included in the upload, so these folders are
provided as destinations but are otherwise empty. Add the original media using
the exact filenames referenced in the source files to restore those local visuals.
The website also uses remote Unsplash images where URLs are present.

The contact form is a front-end demo and does not send submissions to an inbox.
